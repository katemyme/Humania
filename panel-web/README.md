# Panel web (docente) — Humania

Panel para el docente (roles admin y auditor): crear salas, asignar reinos,
editar preguntas y ver reportes.

## Configuración
1. Copia `config.example.js` como `config.js`.
2. Rellena la URL y la anon key de tu proyecto Supabase.
3. Sirve la carpeta con un servidor estático:
   `npx serve .`  o  `python -m http.server`

`config.js` está en .gitignore y no se sube al repo.
